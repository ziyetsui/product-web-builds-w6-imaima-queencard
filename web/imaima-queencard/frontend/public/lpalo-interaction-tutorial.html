Design Token

先锁住原站的视觉 DNA。

原站不是靠阴影和渐变建立层级，而是靠粉底、白面、黑框、大圆角、偏移层、强对比色块和非常直接的字体尺度。复刻时先复制这些 token，再谈组件。

Motion System

动效的共性：快、弹、偏移、层叠。

原站把大多数互动都压在 transform、opacity、height 上。核心手感来自 0.1s 直接偏移、0.5s 弹性展开、15s 或 40s 无限线性循环。

Complete Checklist

以后截图描述时，照这个清单讲。

这一段是给“不会描述，只会截图”的。你可以直接复制其中一项给开发或 AI，它包含触发方式、视觉变化、状态和实现注意点。

页面加载全屏 fixed loader，3 层 lemon/pumpkin/seafoam 背景，2px 黑框，GSAP timeline 依次 scaleX 收起。路由 leave 时 body 加 overflow，enter 后移除。
自定义光标body 使用白色箭头 SVG cursor，按钮和链接使用 hand cursor。教程页右侧有可开关的 cursor 预览，用来说明截图里的鼠标形态。
桌面导航header 绝对定位，左右分布，pointer-events 默认 none，内部 nav 打开 pointer-events。滚动时可加 c-header--hide，把 header 向上移出。
移动导航1280px 以下 header 变 fixed 全屏，高度用 100vh 或 CSS var --vh。burger 为 pumpkin 圆按钮，打开后背景 lemon 从顶部 scaleY 展开。
圆形菜单大圆 100%，小圆 75%，外层 SVG 110%。header 态外圈 15s 逆时针旋转。open 态 z-index 1001，移动端显示 close。
磁吸按钮鼠标进入后目标元素相对中心点 translate，范围 10 到 24px。离开时用弹性曲线回到 translate3d(0,0,0)。
按钮 hover按钮本体白底黑框，hover 时 wrapper translate(10px, -10px)。背后 2 到 3 层 bg 分别偏移，常用 hover color seafoam 或 white。
HoverEffect 类型basic/oval 用圆形或胶囊背板，square 用矩形背板，triangle 用三角形错位，star 用星形错位。所有背板 0.1s ease-out。
互动 hero句子拆词，词拆字。每个字有随机小 bottom 偏移和 transition-delay。hoverable 词出现同义词，背景随机 circle/rectangle/star。
SplitText标题包成 line，line overflow hidden，char 从 y 100% 到 0，opacity 从 0 到 1。滚动进入视窗后按 stagger 播放。
背景条带BarContainer fixed 到屏幕中心，rotate(-25deg) scale(2)，两条 bar 从 left 0 和 99% 起跑，40s linear 无限 translate。
播客卡片白色卡片 10px 圆角黑框，hover 让卡片 translate(20px, -20px)，橙色背板显示，紫色背板 translate(10px,-10px)。
卡片行动下划线action 使用 before 和 after 两条 2px 线。hover 时两条线一起 translateX(200%)，形成下划线被替换的感觉。
随机收听 widget外层宽 30rem、高 25.3rem，内容层 rotate(var(--rotation))。hover 时 infos translate(44px,-30px)，点击播放随机 balado。
耳机点击过场idle 状态点击耳机图标后进入 active：粉底切到多色放射背景，中心点外扩，右上角海盐星爆耳机 scale + rotate 入场，音符轻微漂浮。
问题 widget整体 38.43rem 正方形，wrapper rotate(-20deg)，hover 或 active 时白层和第一色层 translate(34px,-20px)，第二层 translate(17px,-10px)。
问题弹窗状态state=question 显示标题和录音按钮。点击 CTA 后 state=message，显示说明、iframe 和 close。外部点击或 close 返回 question。
底部播放器fixed bottom，yellow 背景，上下 2px 黑框。closed 为 translateY(100%)，open 为 translateY(0)。full 态显示标题、说明和更多链接。
播放器链接入场了解更多圆形链接 scale(0) rotate(180deg) 入场到 scale(1) rotate(0)，进入用 .4/.6/.3/1.3 曲线，退出用 .61/-.21/.47/.72。
Smooth scroll页面启用 has-scroll-smooth 时 body overflow hidden，滚动容器是 js-locomotive。路由数据更新后必须 emit update-locomotive。
Swiper 轮播touch start 保存 startX/startY，touch move 判断角度，超过 threshold 后阻止点击，release 后 snap。边缘支持 resistance。
Lazyloadlazyload 和 lazyloading opacity 0，lazyloaded opacity 1，transition opacity .8s。图片高度用 aspect-ratio 或 padding-top 保持布局不跳。
信息 widgettext widget 用白底或彩底承载标题和说明；image widget hover 启用 square HoverEffect，背景多层错位。
事件卡片事件卡可带 rotation CSS variable，并包在 Magnetic 里。hover 主要反馈是按钮错位和整体轻微吸附。
响应式979px 以下 wrapper padding 从 80px 降为 20px；480px 以下大标题降级，组件宽度改为 100% 或 scale(.8)。
