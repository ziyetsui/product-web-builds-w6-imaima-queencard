## 目标

用户永远不面对提示词。卡片回弹到输入框时只显示填空题（最多三个元素）；
发送给图像模型的完整提示词由系统用「原帖 DNA + 用户变量」自动组装。

```text
爆款帖子 → DNA（analyzeSource 静态提取）→ 变量（用户填空）
        → Prompt Composer（系统组装）→ GPT Image 2（参考图 + 指令）
```

## 非目标

- 不做 AI 驱动的 DNA 抽取器（本期 DNA 为静态规则提取；升级另立 feature）
- 不改数据库 schema（Pattern JSON 入库另立 feature）
- 不动生成链路、积分、支付

## 可见层（用户填空）

| 槽位 | 谁填 | 默认值 |
| --- | --- | --- |
| 新主题 topic | 用户，唯一必填 | 原帖具体话题（排除泛化标签） |
| 新标题 title | 系统联动生成，可改 | 标题骨架 × 新主题 实例化 |
| DNA 标签 | 只读展示 | 视觉机制清单 |

联动规则：改 topic 时，若 title 仍含旧 topic 则原位替换；手改过且不含旧
topic 的 title 不被覆盖。

## 隐藏层（v4 契约）

```text
参考已附上的原图，逐项复刻原图的{visual}，画风、构图、配色与字体版式保持一致，并去除图片中的水印和平台账号字样。只改两处：主标题换成「{title}」，画面主体从原主题换成「{topic}」，其余元素照原图复刻。画面中只允许出现作品本身的文字，禁止出现任何说明、分析或指令类文字。
```

固定条款（非变量）：去水印句 + 双禁令（防分析文字入画）——对应线上验证过的
「图片不动、只换标题」配方（见 .gba/0001 的记录文档）。

## 标题实例化（语法安全规则）

1. 原标题含原主题 → 原位替换（最保语法）
2. `…谁懂？` → `{topic}，谁懂？`
3. `(如何)?用…时间/天…` → `如何用7天时间搞定{topic}`（名词友好）
4. 兜底 → 保留原标题

## 兼容

`normalizePromptForEditor` 把 v2（`生成一组新的…复刻参数…`）和
v3（`保留原图的…标题骨架…`）旧提示词进编辑器时自动升级为 v4。
