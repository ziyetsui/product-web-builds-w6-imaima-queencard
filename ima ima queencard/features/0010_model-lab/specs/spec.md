# 0010 模型实验室 · Model Lab

| 字段 | 内容 |
| --- | --- |
| 状态 | 规格草案，待评审 |
| 建议分支 | `feat/model-lab` → `.trees/model-lab/` |

## 目标

系统性地评估并接入多个图像生成模型，让「复刻爆款」在质量、成本、速度之间
有可选档位；沉淀一套可重复的模型评测流程，而不是一次性的手感对比。

## 背景

当前唯一主力是 GPT Image 2（gptproto 渠道，参考图走 `gpt-image-2-edit`）。
产品的核心卖点「图片不动、只换标题」强依赖模型的**参考图编辑**能力——
这是评测的第一优先维度，纯文生图强的模型未必胜任。

## 非目标

- 不做用户侧的模型自动推荐（先人工定档位）
- 不改积分定价结构（各模型积分数沿用现有 `calculateModelCredits` 机制配置）
- 不接入视频模型

## 设计

### 1. 评测矩阵（先于接入）

固定 10 张代表性卡片（覆盖搞笑漫画/清单/科普/情绪疗愈等类目）× 统一的
v4 提示词，每个候选模型各生成一轮，按四维打分：

| 维度 | 权重 | 判据 |
| --- | --- | --- |
| 风格锁定度 | 40% | 画面/构图/配色与参考图的一致性；标题是否正确替换 |
| 文字渲染 | 30% | 中文标题是否清晰无乱码 |
| 成本 | 20% | 单图 API 成本 → 折算积分 |
| 速度 | 10% | P50 生成耗时 |

### 2. 接入方式

- 模型清单集中在 `src/config/image-generation-models.ts`（id、能力、最大
  出图数、积分），新增模型只改配置 + provider 适配层
- provider 适配收敛在服务端生成链路（`services/image-generation.ts`），
  前端 Composer 的模型选择器自动读取配置渲染

### 3. 评测产出物

评测结果（打分表 + 样张对比图）归档到本 feature 的 `docs/`，作为
上/下架模型的决策依据。

## 候选清单（待评审补充）

- GPT Image 2（基线，已接入）
- Seedream / 即梦系列（中文文字渲染口碑好）
- Nano Banana / Gemini 图像系列（编辑能力强）
- FLUX 系列（成本低，编辑能力待验证）
