# 模块 01：路由、入口与 seed 交接

## 1. 模块目标

让用户从提示词库、空白入口或历史任务进入同一个 `/generated` 工作台，并准确恢复上下文。进入页面本身不得创建任务、冻结积分或调用模型。

## 2. 路由职责

| 路由 | 职责 | 不承担的职责 |
| --- | --- | --- |
| `/prompts` | 案例发现、筛选、编辑 seed、选择最多 3 张参考图 | 不创建真实生成任务，不扣积分 |
| `/generated` | 恢复 seed、选择模式和参数、创建任务、展示结果、访问历史 | 不重复实现案例搜索与完整案例详情 |
| `/generated?taskId=<id>` | 打开当前用户已有任务，展示任务快照和结果 | 不允许通过 seed 参数覆写任务记录 |
| `/generated/[taskId]` | 兼容旧链接，重定向到 `/generated?taskId=<id>` | 不渲染第二套任务详情页 |

## 3. 入口类型

### 3.1 从提示词库进入

用户在 `/prompts` 选择案例并点击“生成”后：

1. 系统收集当前编辑后的提示词、所选模型、画幅、输出数量、分辨率、参考图和案例来源。
2. 系统跳转到 `/generated`，生成页默认处于可编辑的 `ready` 状态。
3. 如果 seed 包含 1–3 张参考图，默认模式是 `image-to-image`。
4. 如果 seed 不包含参考图，默认模式是 `text-to-image`。
5. 页面显示紧凑的来源标签和“返回提示词库”入口。
6. 跳转完成时，`POST /api/v1/image-generations` 调用次数必须是 0。
7. 只有用户在 `/generated` 再次点击“生成”后，系统才创建任务。

### 3.2 直接打开空白生成页

用户直接访问 `/generated` 时：

1. 若当前作用域存在未完成草稿，系统恢复该草稿。
2. 若没有草稿，系统使用纯文生图默认值：空提示词、零张参考图、默认文生图模型、`1:1`、1 张、自动分辨率。
3. 空提示词时生成按钮禁用。
4. 页面不得伪造来源案例、案例标题或参考图。

### 3.3 从历史任务进入

用户点击历史记录或打开带 `taskId` 的 URL 时：

1. 系统优先读取服务端任务，不使用 URL seed 或本地草稿覆写任务快照。
2. 系统验证任务属于当前用户；他人任务统一返回 404，不泄露任务是否存在。
3. 任务处于 `queued` 或 `generating` 时恢复轮询。
4. 任务处于终态时只读取一次，不启动周期轮询。
5. 用户点击“继续创作”后，系统把任务参数复制为新草稿，不修改原任务。

### 3.4 登录中断恢复

匿名用户可以查看 seed 和编辑草稿，但不能创建任务。用户点击生成后：

1. 客户端收到 401 或预先发现未登录时，保存当前草稿。
2. 跳转到 `/login?from=<同源相对路径>`。
3. `from` 必须是以 `/` 开头的同源相对路径，拒绝协议、域名、`//` 和其他外部跳转形式。
4. 登录成功后返回 `/generated`，恢复原草稿和来源。
5. 登录跳转过程不创建任务、不冻结积分。

## 4. Seed 数据契约

### 4.1 规范字段

新生成链接只写一套规范字段。服务端和页面继续读取现有别名，以兼容旧链接。

| 规范字段 | 类型 | 说明 |
| --- | --- | --- |
| `source` | `manual \| prompt-library \| regenerate` | seed 来源 |
| `prompt` | string | 用户最终可编辑提示词 |
| `mode` | `text-to-image \| image-to-image` | 新链接显式写入；旧链接可以推断 |
| `model` | string | 前端模型 ID |
| `aspect_ratio` | string | 画幅比例 |
| `output_count` | integer | 输出数量 |
| `resolution` | `auto \| 1k \| 2k \| 4k` | 分辨率 |
| `source_case_id` | string | 提示词库案例 ID |
| `source_case_category` | string | 案例分类 |
| `source_note_url` | HTTPS URL | 原帖链接 |
| `source_author_url` | HTTPS URL | 作者链接 |
| `title` | string | 页面显示标题，不代替 prompt |
| `reference_images` | JSON string array | 仅用于站内静态路径或安全 HTTPS URL |
| `handoff_id` | opaque string | 本地文件交接标识，不含文件内容 |

`template`、`reference_image_urls`、`input_images`、`reference_images[]`、`reference_image_urls[]` 和 `input_images[]` 等既有别名继续读取，但新链接不得再重复写入。

### 4.2 推断规则

- 新链接有 `mode` 时，以合法 `mode` 为准，并由服务端再次验证模型和参考图数量。
- 旧链接没有 `mode` 时：去重后的参考图为 0 张则推断为 `text-to-image`；为 1–3 张则推断为 `image-to-image`。
- `taskId` 存在时，任务数据优先级最高，并移除冲突的 `view=history` 和 seed 参数。
- 没有 `taskId` 且 `view=history` 时进入历史视图；seed 保留在草稿中但不覆盖历史列表。
- 明确 seed 的优先级高于本地草稿。
- 无明确 seed 时才恢复当前作用域草稿。
- 服务端返回任务后，任务字段高于所有客户端推断。

## 5. 参考图交接与隐私

### 5.1 站内静态案例图

`/xhs-cases/**` 等站内静态路径可以写入 `reference_images`。生成页规范化后去重，并最多保留 3 张。

### 5.2 本地上传图片

本地图片不得以 Data URL、Base64、Blob 内容或重复编码形式写入 URL。原因包括：

- URL 长度可能超过浏览器或代理限制。
- 浏览历史、服务端访问日志、分析 SDK 和复制链接可能泄露图片内容。
- 当前实现把同一图片写入多个参数，会成倍放大 URL。

在不引入对象存储的本版本中，使用浏览器侧一次性交接存储：

1. `/prompts` 为本地选择生成 `handoff_id`。
2. 原始文件允许 JPEG、PNG、WebP，单张不超过 10 MB；浏览器在交接前自动校正方向、限制最长边 4096px，并压缩为 JPEG/WebP，每张规范化后不超过 800 KiB。
3. 规范化 Blob 和必要元数据写入 IndexedDB，不写入 localStorage、sessionStorage 或 URL。
4. `/generated?handoff_id=<id>` 在同一浏览器读取 Blob 并恢复预览。
5. 创建任务时把规范化 Blob 转为 Data URL，最多 3 张；JSON 请求体总大小不得超过 3.5 MB。服务端在解析后再次验证每张解码数据不超过 800 KiB。
6. 成功恢复后将记录标记为已消费；保留至任务提交完成或 30 分钟 TTL 到期。
7. 找不到或过期时，页面显示“本地参考图已失效，请重新选择”，保留 prompt 和其他参数。
8. 包含本地图片的链接不可跨设备分享；界面不得暗示其可分享。
9. 无法在 800 KiB 内得到有效图片时拒绝该文件并指出具体原因，不发送未经限制的原图。

本方案只解决路由交接泄露，不声称完成服务端永久资产存储。

## 6. URL 清理

- 页面解析完 legacy 重复参数后，使用 `history.replaceState` 或 Next Router 替换为规范 URL。
- 规范化不得触发第二次 seed 应用，也不得清空浏览器后退记录。
- 任务创建成功后 URL 变为 `/generated?taskId=<newTaskId>`。
- 从历史打开任务后，浏览器后退返回此前页面或历史视图，不进入重复重定向循环。

## 7. 草稿规则

- 草稿按用户和上下文分区：`manual`、`case:<sourceCaseId>`、`task:<taskId>:iterate`。
- 登录用户的草稿 key 必须包含用户 ID；匿名草稿使用单独命名空间。
- 登出后清理内存中的账户草稿引用，不能让第二个账户自动恢复前一个账户的私人 seed。
- 草稿包含 prompt、模式、参考图引用、模型、画幅、张数和分辨率。
- 草稿保存失败时显示非阻断提示；不得静默把大图片继续塞回 localStorage。

## 8. 错误处理

| 情况 | 页面行为 |
| --- | --- |
| 不合法 `taskId` | 显示任务不存在状态和返回生成页入口 |
| 他人 `taskId` | 与不存在任务相同，不透露所有者 |
| Seed prompt 超过 2000 字 | 截止恢复并显示长度错误，不自动静默截断 |
| 参考图超过 3 张 | 去重后保留前 3 张，同时显示兼容旧链接提示 |
| 本地 handoff 过期 | 保留文本参数，要求重新选择本地图 |
| 不合法外部参考图 URL | 标记具体图片无效，生成按钮禁用 |
| 登录返回路径不安全 | 丢弃 `from`，登录后进入 `/generated` |

## 9. 隐私日志规则

- 地址栏、document URL、服务端访问日志和现有分析 SDK payload 中不得出现 Data URL、Base64 图片内容或完整本地文件名。
- 本版本不新增业务分析事件，避免把 Analytics 扩张混入生成页改版。
- 错误日志只能记录 handoff ID、图片序号、MIME、规范化字节数和错误类别，不记录图片内容。
