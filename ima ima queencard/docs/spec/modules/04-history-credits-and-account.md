# 模块 04：历史、积分与账户上下文

## 1. 模块目标

在不新建 Dashboard 的前提下，让用户在生成工作台内完成跨任务导航：新建生成、返回提示词库、查找历史、查看积分和进入会员页。所有账户和积分信息必须来自真实接口，不再显示固定的 `U / 用户 / --`。

## 2. 工作台侧栏

### 2.1 桌面导航

侧栏从上到下包含：

1. MM-Coincard Wordmark 和折叠按钮。
2. `图片生成`：进入 `/generated` 的新建或当前草稿视图。
3. `提示词库`：进入 `/prompts`。
4. `生成历史`：进入 `/generated?view=history`。
5. `积分中心`：进入现有 `/credits`。
6. `会员方案`：进入现有 `/pricing`。
7. 底部真实可用积分。
8. 底部账户入口；未登录显示“登录”，已登录显示头像回退、昵称或邮箱和当前计划。

本版本不新增 `/dashboard`、`/membership` 或 `/account` 路由。

### 2.2 折叠

- 完整侧栏宽度 208px；平板和用户主动折叠后宽度 72px。
- 折叠后保留图标、当前项状态和 Tooltip。
- Wordmark 缩为品牌 `Q`，不截断成无法识别的文字。
- 折叠偏好按用户存储；匿名偏好使用独立 key。
- 移动端不显示 72px 常驻栏，而使用 Drawer。

### 2.3 当前项

- `/generated` 和 `/generated?taskId=...` 高亮“图片生成”。
- `/generated?view=history` 高亮“生成历史”。
- 高亮只使用一个主层级：柠檬黄背景、炭黑描边和 2px 硬阴影。

## 3. 顶部工具条

桌面顶部工具条包含：

- 从案例进入时显示“返回提示词库”。
- 非案例入口显示当前面包屑或“图片生成器”。
- `任务历史` 次级按钮。
- `新建` 主按钮；点击前检查当前未提交草稿。

有未提交修改时点击“新建”：

- 打开确认 Dialog。
- `清空并新建`：清除当前作用域草稿后新建唯一的 manual 草稿。
- `取消`：保持当前内容。

本版本不引入多个并行 manual draft ID，因此不提供“保留并新建”。案例草稿仍按 `case:<sourceCaseId>` 独立保存，不受 manual 草稿清空影响。

任务正在运行时，“新建”只切换新草稿视图，不取消运行中任务；运行中任务仍可从历史恢复。本版本创建按钮在同一工作台只允许一个前台提交请求，但不假定服务端全局只有一个任务。

## 4. 历史视图

### 4.1 进入方式

- 桌面侧栏“生成历史”。
- 顶部“任务历史”。
- 移动端导航 Drawer。
- URL 使用 `/generated?view=history`，刷新和浏览器后退后保持视图。

### 4.2 列表字段

每条历史记录显示：

- 第一张成功资产缩略图；没有资产时显示状态占位，不使用假图片。
- prompt 前 80 个可见字符。
- 模式：纯文生图或参考图生成。
- 模型显示名。
- 状态。
- 成功数量 / 请求数量。
- 最终扣除积分；运行中显示冻结积分。
- 创建时间；跨日期时显示绝对日期，同日可以显示相对时间。
- 来源案例分类或“手动创建”。

### 4.3 排序与分页

- 只返回当前用户任务。
- 按 `createdAt DESC, id DESC` 排序，保证相同时间稳定顺序。
- 每页 20 条。
- 继续使用现有 offset API，并以 `createdAt DESC, id DESC` 保证稳定顺序；45 条 fixture 必须可以全部到达，不能固定只取 36 条。
- 加载更多时不得重复或跳过记录。
- 已加载列表在打开某条任务后返回时保持滚动位置。

### 4.4 搜索与筛选

搜索范围：prompt、案例分类、模型显示名或 ID。状态筛选支持全部、运行中、完成、部分成功、失败。

- 输入 300 ms debounce。
- 新查询取消或忽略旧请求。
- 空字符串恢复完整列表。
- 搜索和状态通过 URL 参数表达，例如 `view=history&q=漫画&status=failed`。
- 搜索结果为空时显示空状态、清除筛选和新建生成入口。

### 4.5 打开任务

点击记录进入 `/generated?taskId=<id>`。任务卡本身是一个可键盘聚焦的链接或按钮；内部次级操作不得嵌套不可用交互元素。

## 5. 用户隔离

- GET 历史只查询当前登录用户。
- GET 任务详情和下载资产都验证归属。
- 他人任务或资产统一返回 404。
- 前端不能只靠隐藏列表保证隔离。
- 用户 A 的草稿、搜索和折叠偏好不得自动出现在用户 B 会话。
- 退出登录后清除账户级查询缓存和内存状态。

## 6. 积分上下文

### 6.1 显示来源

侧栏与移动顶部的可用积分来自 `/api/v1/credit/balance` 或现有 `useCreditBalance`。页面不得显示静态 `--` 作为已加载状态。

状态定义：

- 加载中：固定宽度 skeleton，避免侧栏跳动。
- 已加载：`<N> 可用积分`。
- 失败：显示重试图标和 Tooltip，不把失败解释为 0。
- 未登录：显示“登录后查看积分”。

### 6.2 预估、冻结与结算

工作台同时区分：

- `可用积分`：balance API 返回值。
- `预计消耗`：estimate API 返回值。
- `冻结积分`：运行中任务 requested credits。
- `本次扣除`：终态 settled credits。

不得把预计消耗提前从 UI 余额永久扣除。任务创建成功后可以乐观刷新余额，但必须立即用 balance API 对账。

### 6.3 积分不足

创建前发现可用积分不足：

1. 生成按钮进入不足状态。
2. 显示“需要 N，当前可用 B”。
3. 提供“获取积分”，进入 `/pricing?source=generated&returnTo=<安全相对路径>` 或现有定价页兼容参数。
4. 不调用 create API。

服务端返回 402：

1. 不新增 task、hold 或 transaction。
2. 保留草稿。
3. 刷新 balance，避免使用过期余额。
4. 展示相同获取积分入口。

## 7. 账户入口

### 7.1 已登录

显示优先级：

1. 用户上传头像；若无，则使用昵称首字符；再无则使用邮箱首字符。
2. 主文字：昵称；若无则邮箱本地部分。
3. 次文字：Free、Creator 或 Studio 等真实计划名。

点击后打开小型菜单：

- 积分中心 `/credits`。
- 会员方案 `/pricing`。
- 退出登录。

本版本不新增账户资料编辑页。

### 7.2 未登录

显示“登录”，链接包含当前安全相对路径作为 `from`。登录后返回原草稿或 task。

### 7.3 退出登录

- 调用现有 Better Auth 客户端的 sign out。
- 清除用户级 Query cache、草稿引用和积分状态。
- 退出后可以留在 `/generated` 的匿名草稿模式，但不能继续显示前一个用户的历史和积分。

## 8. 移动端导航

- 顶栏显示菜单按钮、紧凑 Wordmark 和积分。
- 菜单按钮打开左侧 Drawer。
- Drawer 内容与桌面侧栏一致。
- 历史可以在主区域打开；不得用压缩到 72px 的常驻侧栏占用手机宽度。
- Drawer 打开时焦点被限制在其中，Escape 和关闭按钮均可关闭，关闭后焦点返回菜单按钮。

## 9. 加载与错误状态

| 区域 | 加载中 | 失败 |
| --- | --- | --- |
| 用户 | 头像和两行 skeleton | 显示登录或重试，不显示假昵称 |
| 积分 | 固定宽度 skeleton | 重试入口，不显示 0 |
| 历史首屏 | 6 条结构 skeleton | 错误说明、重试和返回生成 |
| 加载更多 | 列表底部 spinner | 保留已加载结果，允许重试 |
| 搜索 | 输入框保持可用 | 显示查询失败，不清空旧列表 |

## 10. 非目标

- 不在生成工作台内复制完整 `/credits` 流水。
- 不显示账单、发票、取消订阅或付款方式。
- 不新增 Dashboard KPI 卡。
- 不修改 Creator/Studio 权益和功能 gating。
- 不把历史改为公开社区或灵感画廊。
