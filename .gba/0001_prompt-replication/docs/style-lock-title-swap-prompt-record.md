## 提示词模板（线上版原文）

```text
生成一组新的{主题}主题：标题《{标题}》，复刻参数“{复刻参数}”
```

抓取时的实际填充值（首屏示例卡「鸡，谁懂？」）：

| 槽位 | 值 |
| --- | --- |
| 主题 | 搞笑漫画 |
| 标题 | 冷笑话，谁懂？ |
| 复刻参数 | 保留原图的视觉风格、构图和内容节奏（节奏、反差包袱、分镜密度和标题语气）；沿用原标题句式，将主题变量替换为新主题 |

拼装后的完整提示词：

```text
生成一组新的搞笑漫画主题：标题《冷笑话，谁懂？》，复刻参数“保留原图的视觉风格、构图和内容节奏（节奏、反差包袱、分镜密度和标题语气）；沿用原标题句式，将主题变量替换为新主题”
```

## 去水印追加句（手动输入，达成"图片不动"效果的关键）

在复刻参数末尾手动追加去水印指令后，模型表现为：完整保留参考图的画面，仅重绘标题文字。追加写法（示例，实际用词以当时输入为准）：

```text
；去除图片中的水印和平台账号字样
```

> 注：去水印句不在代码模板里，是生成时在输入框里手动补的。此处按记忆重构，
> 语义准确、字词可能有出入。

## 为什么这一版能"锁住"画面

1. 复刻参数以"保留原图的视觉风格、构图和内容节奏"开头——给了模型明确的保留清单；
2. "沿用原标题句式，将主题变量替换为新主题"把改动范围收窄到标题一处；
3. 追加的去水印句让模型进入"编辑原图"而非"重新作画"的模式（gpt-image-2-edit 能力），
   于是画面被原样保留，只有文字层被替换。
