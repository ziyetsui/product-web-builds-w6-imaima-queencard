# Prompt Replication Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every `/prompts` card generate a source-aware, high-similarity structured rewrite prompt.

**Architecture:** Extract pure prompt-replication helpers from the page component. The helpers classify source metadata, derive a concrete topic and source mechanisms, and build the exact three-slot prompt contract. The page keeps only card rendering and passes the generated prompt into the existing structured editor.

**Tech Stack:** Next.js 16, TypeScript, Vitest, React, existing `ImageGenerationComposer` structured editor.

## Global Constraints

- Preserve prompt shape: `生成一组新的{type}主题：标题《{title}》，副标题“{replicationSubtitle}”`.
- Preserve source type and source-specific mechanisms; never replace them with generic category copy.
- Exclude generic tags from topic selection.
- Keep the yellow title slot and blue subtitle slot editable.
- Do not change generation APIs, reference-image handling, or billing behavior.
